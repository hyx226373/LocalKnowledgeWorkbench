# Notepad++ 适配器完成程度说明（第 9 轮合并后，2026-10-03）

**定位：这是「外部程序启动」适配（displayMode = `external-managed`，界面标签“外部窗口启动”），不是内嵌窗口。** Notepad++ 在它自己的窗口里运行；工作台面板只是一个状态占位，提供启动、切到前台、关闭和备份摘要。

## 能做什么

| 能力 | 状态 | 在哪里验证 |
|---|---|---|
| 只启动声明的程序：`%ProgramFiles%[ (x86)]\Notepad++\notepad++.exe`，固定参数模板（打开文件 / 打开并跳到行 / 空白，均带 `-multiInst -nosession`） | 规则已实现 | SDK 模拟宿主单测；核心 `tests/app-launch.test.ts`（模拟外部程序） |
| 启动前要用户授权（授权框列出程序路径、签名者、参数模板、备份范围、可恢复/不可恢复） | 已实现并接入工作台 | 核心 e2e `e2e-apps.mjs`（Linux） |
| 签名者 `Notepad++` + 版本 ≥ 8.8.7 校验，不通过不启动 | 校验接口已实现（`winVerify.ts`，PowerShell `Get-AuthenticodeSignature`） | **只在 Linux 上测了输出解析，未在 Windows 运行** |

| 窗口跟踪（尽力而为）、切到前台、优雅关闭 | **未实现**（核心只有 `windowTracking` 状态字段，状态停在“正在查找窗口”） | — |

## 不能做什么（设计如此）

- 不能把 Notepad++ 窗口嵌进工作台（未做“已验证嵌入”，默认关闭；原因见 README“已验证嵌入”）。
- 不能启动其他程序、不能附加自定义参数、看不到 exe 路径和最终命令行。
- 不能恢复备份范围以外的改动：“另存为”或新建的文件、同文件夹其他文件、已登记文件夹以外的文件；Notepad++ 自己的设置/会话/插件/最近文件列表（`%APPDATA%\Notepad++`）；注册表、网络操作、打印。
- 不能在工作台里显示 Notepad++ 的画面或缩略图（面板没有截图）。

## 接线状态（核心第 9 轮合并后）

1. **R1 已接线**：`ctx.process` 经沙箱运行时 → 主进程 `AppHost`/`AppLaunchService`；命令面板“新建外部程序项目：Notepad++…”创建应用档案（只选声明过的启动方式与文件）；`CURRENT_PHASE = 3`，app 条目可用。
2. **R2 已接线**：恢复入口是操作记录的统一撤销（不单独做备份列表）；目标文件超限时弹原生确认框“不备份也启动？”，默认“不启动”。
3. **未实现**：窗口跟踪 / 切到前台 / 关闭的 Win32 实现（R8）；面板上这两个按钮保持灰色。
4. **只在 Linux 上用模拟外部程序测过**：找 exe、签名校验、真实 spawn、原生确认框都没有在 Windows 上运行过。

## 需要在 Windows 真机核对

- [ ] 文件属性 → 数字签名（或 `Get-AuthenticodeSignature "C:\Program Files\Notepad++\notepad++.exe" | Format-List`）里显示的**签名者名称**是否就是 `Notepad++`（宿主按证书主题 CN 完全匹配）。若不同，改 manifest 的 `verify.publisher`。
- [ ] 8.8.7 及以上版本 `Status` 为 `Valid`；8.8.6 及以下被拒绝。
- [ ] `FileVersionRaw` 返回四段版本号（宿主取前三段比较）。
- [ ] `-multiInst -nosession` 下每次启动是独立进程、进程活到窗口关闭（退出码 = 窗口关闭）。
- [ ] 32 位安装（`%ProgramFiles(x86)%`）能被找到。
- [ ] 中文路径、带空格路径作为参数传给 Notepad++ 正确打开（参数数组、`shell:false`）。
- [ ] 64 MB 以上的日志文件：先弹“不备份也启动？”，同意后启动并在面板标注“本次未备份”。
- [ ] 在 Notepad++ 里修改并保存 → 退出 → 工作台列出该文件被修改 → 恢复成功；“另存为”的新文件不在列表中（不可恢复）。
