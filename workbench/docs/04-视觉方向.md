## (a) 安静书房

暖纸色底（`#f6f1e7`）、深棕文字与强调色，正文和标签用衬线字体（思源宋体/Noto Serif CJK，Windows 回退宋体），行高 1.9、阅读区最宽 720px，界面框架（侧栏、标签、状态栏）与阅读区对比度很低，“框架退后、文字在前”。**适合**以长时间阅读、做读书笔记为主的用户（文科研究、读书会、示例分类复习），尤其在白天/纸质感偏好下。**取舍**：信息密度低，树和标签可见条目少；低对比度框架在强光或低质量屏幕上可辨识度下降，需单独校对可访问性；衬线中文字体在 Windows 上需要随应用携带或依赖系统字体，小字号时渲染不如黑体清晰；深色变体需要单独设计“夜间纸”色板。

## (b) 专业工具

深色、紧凑、VS Code 风格：行高 20px、12px 界面字号、标签/路径/页码/状态用等宽字体强调，2px 圆角、无阴影，蓝色状态栏。一屏能看到最多的树条目和标签，适合键盘与命令面板驱动。**适合**开发者、数据/工程类用户、同时管理大量文件和多根的重度用户，也最适合与 Agent 协作场景（日志、操作记录、差异视图天然契合）。**取舍**：长篇中文阅读舒适度最差（需要在阅读区放宽行高或提供“阅读模式”）；对非技术用户显得冷硬、“像编程工具”；深色界面中嵌入白底 PDF 对比强烈，需提供 PDF 反色/暖色滤镜。

## (c) 明亮卡片

浅灰蓝底 + 白色圆角卡片（侧栏、每个分栏分组都是独立卡片，间隙 10px、圆角 14px、轻阴影），紫色强调色，行高 30px、更大的留白和标签高度，激活标签用强调色下划线。**适合**轻度到中度使用的普通知识工作者、学生，强调“现代、友好、好上手”，也便于后续做卡片式笔记/知识链接视图。**取舍**：留白和间隙占用空间，1280×800 下可视内容最少（树约少 30%）；多分栏时卡片间隙让拖拽分栏的边界不如 (b) 明确；阴影与圆角在低端显卡/远程桌面上可能有渲染开销；强调色较强，长时间阅读时需要克制使用。

## 建议的决策方式

- 先定**主方向**（决定默认密度、字体策略、组件形态），其余可作为“可选主题”保留——令牌体系已支持任意切换，成本在于每个方向都要维护浅/深两套并逐个组件验收。
- “框架用 (b) 或 (c)，阅读区用 (a)”现在可直接在外观菜单中组合（外框样式与阅读区样式分开选择，阅读区令牌为 `read-*`）。
