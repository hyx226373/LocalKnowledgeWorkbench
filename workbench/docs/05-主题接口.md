# 05 主题接口（主题接口 1.0.0，宿主 API 0.2.0）

> 读者：主题外包、核心开发者。外包的操作步骤见 `theme-kit/README.md`；完整令牌表与组件选择器表由 `npm run theme:kit` 生成在 `theme-kit/TOKENS.md`、`theme-kit/COMPONENTS.md`。
> 单一来源：`src/shared/theme-contract.json`（由 `scripts/gen-theme-contract.py` 生成）。核心样式、校验器、状态表、文档都从它派生。

> **主题接口 2.0.0（第 9 轮）**：颜色角色、统一状态集合（default/hover/active/focus-visible/disabled/selected/dragging/drag-over）、22 个组件的权威清单、阅读专注模式令牌（read-focus-*）、PDF 深色滤镜改为面板内可选设置。详见 `theme-kit/CHANGELOG.md` 与 `theme-kit/MIGRATION-v1-to-v2.md`；v1 主题包按兼容模式加载。本文下文中与 v2 冲突之处以 theme-kit 生成的 TOKENS.md / COMPONENTS.md 为准。

## 1. 三个独立的轴

| 轴 | manifest 字段 | 作用范围 | 选择方式 |
| --- | --- | --- | --- |
| 外框样式 | `contributes.chromeThemes[]` | 顶栏、侧栏、目录树、标签与分组、分隔条、搜索结果、菜单/命令面板、插件侧栏、状态栏、对话框、占位提示、视图工具栏 | 外观菜单“外框样式” |
| 阅读区样式 | `contributes.readingThemes[]` | 所有视图的内容区：Markdown、文本、PDF 背景与页面、CSV 表格 | 外观菜单“阅读区样式” |
| 布局预设 | `contributes.layoutPresets[]` | 分栏排列（几栏、横竖、比例）与侧栏宽度 | 工作区菜单 / 命令面板“应用布局预设：…” |

- 明暗是第四个选择：浅色 / 深色 / 跟随系统。每个外框样式与阅读区样式都**必须**提供 `light` 与 `dark` 两个变体。
- 三项选择互相独立，任意组合都必须可用（例如 B 外框 + A 阅读区 + 深色）。外观是全局设置，保存在 `layout.ui.appearance`，不属于工作区。
- 切换外观**不改变**：打开的文件、标签顺序、分栏结构与比例、阅读进度（E2E 验证，见 03 T12 验收 3）。外框的尺寸令牌（顶栏、标签高度）会改变可用像素高度，但分栏比例不变。
- **会改变面板排列的一律是布局预设**，不是主题。布局预设只改网格，不改条目与状态。

## 2. 主题包格式

```
<主题包文件夹>/
  theme.json            必需
  chrome.css            可选，受限 CSS（外框）
  reading.css           可选，受限 CSS（阅读区）
  layouts/*.json        可选，布局预设
```

```jsonc
{
  "$schema": "../theme.schema.json",
  "id": "contractor.a",                    // 全局唯一；kb.theme.* 为内置保留
  "name": "方向 A",
  "version": "0.1.0",
  "engines": { "workbench": "^0.2.0", "themeContract": "^1.0.0" },
  "contributes": {
    "chromeThemes":  [{ "id": "a", "label": "方向 A 外框",
                        "light": { "tokens": { "color-bg": "#f6f1e7" }, "css": "chrome.css" },
                        "dark":  { "tokens": { "color-bg": "#1d1a16" }, "css": "chrome.css" } }],
    "readingThemes": [{ "id": "a", "label": "方向 A 阅读区",
                        "light": { "tokens": { "read-fs": "16px" }, "css": "reading.css" },
                        "dark":  { "tokens": { "read-fs": "16px" } } }],
    "layoutPresets": [{ "file": "layouts/focus.json" }]
  }
}
```

- 主题包是**纯数据**，不执行任何代码。宿主把它转换成一个 `kind:'theme'` 的插件记录，出现在插件面板中，可禁用。
- 来源：内置（`themes/study|pro|bright`，随应用打包）、已安装（外观菜单“安装主题包（文件夹）…”复制到 `userData/themes/<id>/`）、开发中（环境变量 `KB_THEME_DIRS`，多个用系统路径分隔符）。
- 读取限制：只读取 `theme.json` 中引用的、位于包目录内的文件；单文件 ≤ 256 KB，总计 ≤ 2 MB。
- 未设置的令牌使用默认值（报告为警告，不是错误）。

## 3. 令牌（v2：122 个，含颜色角色）

令牌名在 `theme.json` 中不带前缀，在 CSS 中写作 `var(--kb-<名称>)`。每个令牌都有语义说明与浅色/深色默认值（完整表见 `theme-kit/TOKENS.md`）。

| 轴 | 分组 | 数量 | 令牌 |
| --- | --- | --- | --- |
| 外框 | 字体 | 10 | `font-ui` `font-mono` `font-ui-accent` `fs-xs` `fs-sm` `fs-md` `fs-lg` `fs-xl` `fw-strong` `ls-caps` |
| 外框 | 间距 | 6 | `space-1` … `space-6` |
| 外框 | 尺寸 | 9 | `size-row` `size-control` `size-topbar` `size-statusbar` `size-tab` `size-sash` `row-inset` `dock-gap` `shell-inset` |
| 外框 | 圆角 | 4 | `radius-sm` `radius-md` `radius-lg` `radius-pill` |
| 外框 | 层级 | 3 | `shadow-1`（卡片、分组）`shadow-2`（弹层）`shadow-3`（对话框） |
| 外框 | 动效 | 3 | `motion-fast` `motion-normal` `motion-ease` |
| 外框 | 颜色 | 45 | 基础面（`color-bg` `color-chrome` `color-chrome-alt` `color-surface` `color-surface-raised` `color-border` `color-border-strong`）、文字（`color-text` `-muted` `-faint`）、强调（`color-accent` `-fg` `-soft`）、交互态（`color-hover` `color-active` `color-selected` `color-selected-fg` `color-focus-ring` `color-disabled-fg` `color-disabled-bg` `color-drag-over` `color-overlay`）、语义（`color-fav` `color-danger` `color-success` `color-warning`）、区域（状态栏、标签、分隔条、输入框、滚动条）、图标（`color-icon-folder/root/file/md/pdf/image/csv`） |
| 阅读区 | 字体 | 6 | `read-font` `read-font-heading` `read-font-mono` `read-fs` `read-fs-code` `read-lh` |
| 阅读区 | 版心 | 3 | `read-max-width` `read-pad-x` `read-pad-y` |
| 阅读区 | 颜色 | 16 | `read-bg` `read-fg` `read-muted` `read-heading` `read-link` `read-quote-bar` `read-code-bg` `read-code-fg` `read-rule` `read-table-head-bg` `read-selection` `read-mark` `read-pdf-backdrop` `read-pdf-page-bg` `read-pdf-page-shadow` `read-pdf-filter` |

合计：外框 80、阅读区 25。规则：
- 外框样式只能设置外框令牌，阅读区样式只能设置 `read-*` 令牌（跨轴设置报错）。
- 值不能包含 `;` `{` `}` `url(` 等（报错并忽略该令牌）。
- 尺寸令牌只影响外观：`dock-gap` 通过分组内边距实现，不改变 dockview 保存的尺寸；`row-inset` 是行的左右缩进。
- 单元测试保证核心 `styles.css` 引用的每个 `--kb-*` 都已声明，且每个声明的令牌都被核心样式使用。

## 5. 受限 CSS

主题 CSS 由宿主解析、校验、加作用域后注入（`scopeThemeCss`）：
- 每条规则的每个选择器都必须以组件钩子类开头（可接后代、伪类、属性选择器）。外框 CSS 只能用外框钩子，阅读区 CSS 只能用阅读区钩子。
- 禁止选择 `html`、`body`、`:root`、`*`、`#id`。
- 禁止布局属性：`position` `display` `float` `flex*` `grid*` `width/height/min-*/max-*` `top/right/bottom/left/inset` `margin*` `z-index` `overflow*` `visibility` `transform` `translate/scale/rotate` `content` `pointer-events` `contain` `zoom` `aspect-ratio` 等（完整列表见 COMPONENTS.md）。`padding`、`border`、`background`、`color`、`font*`、`border-radius`、`box-shadow`、`transition`、`opacity`、`outline` 等外观属性允许。
- 禁止 `url(`、`expression(`、`javascript:`、`@import`；@规则只允许 `@media (prefers-reduced-motion: reduce)` 与 `@media (prefers-contrast: more)`（无 `@font-face`：主题只能用系统字体并写好回退链）。
- 禁止定义或改写 `--kb-*` 变量（令牌只能在 theme.json 中设置）。
- 宿主给每条规则加前缀 `:root[data-kb-chrome="<id>"][data-kb-scheme="<light|dark>"]`（阅读区为 `data-kb-reading`），所以不同主题的 CSS 互不影响。
- 有错误的主题包整体不加载（插件面板显示“不兼容”与原因），不会部分生效。

## 6. 布局预设

```json
{ "id": "study.focus", "label": "专注阅读（单栏）", "sidebarWidth": 240,
  "grid": { "split": "row", "children": [ { "slot": 1 } ] } }
```

- 节点为 `{split:'row'|'column', size?, children:[…]}` 或 `{slot:n, size?}`；嵌套的 split 方向必须交替；slot 从 1 开始连续编号；`size` 是相对比例。
- 应用时：现有分组按顺序放入 slot 1..n；分组多于 slot 时多出的并入最后一个 slot；分组少于 slot 时空 slot 去掉；只剩一个子节点的根被提升。打开的文件、标签顺序、条目状态不变。
- 内置预设：单栏、左右两栏、上下两栏；内置主题包附带 `study.focus`、`pro.three`、`bright.compare`。

## 7. 截图与验收：`npm run theme:shots`

```
npm run theme:shots -- <主题包文件夹 | 内置主题 id> [--out <文件夹>] [--chrome <id>] [--reading <id>]
```
- 用临时数据目录启动生产构建（没有 `out/` 时先 `npm run build`，Windows 用 `npm.cmd` + `shell:true`），复制 `theme-kit/bench-sample` 到临时根（路径含空格与中文），搭建**功能基准界面**：Markdown | PDF / CSV+PNG 分栏、收藏、展开的目录树、显示中的搜索结果、悬停状态的分隔条、插件侧栏。
- `--force-device-scale-factor=1` + 视口模拟固定 1280×800，与屏幕缩放、窗口大小无关；只有 Linux 且无图形显示时才用 xvfb-run。
- 输出 `bench-light.png`、`bench-dark.png`、`states-light.png`、`states-dark.png`（组件状态表，按完整内容尺寸截图）、`report.json`/`report.md`（校验错误与警告、实际生效的全部 `--kb-*` 值）。错误数非 0 时退出码为 1。
- 内置三套的输出在 `verify/theme-shots/<study|pro|bright>/`。

## 8. 版本

- `engines.themeContract`：主题接口版本（当前 1.0.0）。新增令牌/组件/钩子 → 次版本（旧主题包继续可用，新令牌用默认值）；删除或改名令牌、收紧 CSS 规则 → 主版本。
- `engines.workbench`：宿主 API（当前 0.2.0）。
- 内置 A/B/C（`kb.theme.study` / `kb.theme.pro` / `kb.theme.bright`）目前是**占位**实现，等待主题外包按本接口定稿（03 T18）。

## 9. 已知限制

- CSS 校验是宿主自带的轻量解析器，不是完整的 CSS 解析器；遇到无法解析的写法按错误处理。需要随外包交付持续补充反例测试。
- 状态表中的 drag-over 是静态复现；真实拖动时的覆盖层颜色来自 `color-drag-over`。
- `theme:shots` 只在 Linux（xvfb）上运行过；Windows 上的运行（含 125%/150% 缩放、中文路径）尚未验证（03 T9-6）。
