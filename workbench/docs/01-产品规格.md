# 01 产品规格：本地知识工作台（v1）

> 一句话：把电脑上**已有**的文件夹注册为“根”，在一个窗口里收藏、浏览、搜索，并以标签页 + 可拖拽分栏并排阅读多个文件；原文件始终留在原处。
>
> **产品定位（第二轮更新）**：可扩展的个人知识工作台。阅读器、侧栏/底部面板、命令、主题都是扩展点；内置功能本身就是用同一套 API 写的“内置插件”。
>
> **目标（第三轮，产品负责人确认）**：一个顶层窗口、多文档、可恢复的**任务工作台**。“资料集合”负责挑选文件；“工作区”负责保存标签、分栏、尺寸和每个面板的阅读状态，按任务（如“读文献”“写作”）一键切换与恢复。

## 1. 原则（产品约束）

| # | 约束 | 对产品的含义 |
|---|---|---|
| C1 | 原文件不搬家 | 注册根只是“登记”，不复制、不改名、不写入任何隐藏文件。索引与知识元数据存放在应用数据目录（`%APPDATA%\LocalKnowledgeWorkbench`）。 |
| C2 | UI 与 Agent 同一服务层 | 用户在界面中的操作与外部 Agent 的操作走同一套服务；任何人直接改磁盘文件，应用也要通过文件监听 + 启动对账扫描感知。 |
| C3 | 多根、可备份、可迁移 | 收藏、索引、链接、布局可备份；换电脑后只需把每个根“重新指向”新位置。**路径不是身份**：每个文件/文件夹有稳定的资源 ID，收藏/笔记/链接/标签页都引用资源 ID。 |
| C4 | v1 仅本地 | 应用内阅读：文本/代码、Markdown、图片、PDF。其他格式显示“暂不支持”并给出“在资源管理器中显示”。 |
| C5 | 修改可追溯可恢复 | 应用（含 Agent）执行的每个文件修改都记入操作记录；移动/覆盖/删除需先预览，并可从操作记录恢复（删除进入应用暂存区，覆盖前原内容进入应用备份库）。 |
| C6 | 可扩展 | 新格式阅读器、面板、命令、主题由插件提供。工作区只记录**条目**（来源类型 + 适配器 id + 引用 + 显示方式 + 小的版本化状态），面板只引用条目 id；换掉/卸载某个阅读器不会破坏布局。 |
| C7 | 外观一致可换 | 所有界面颜色/字体/间距/圆角/阴影/动效来自设计令牌。外观分三个独立的轴：外框样式、阅读区样式、布局预设；每个样式都有浅色与深色。切换外观不改变打开的文件、分栏位置与阅读进度。 |
| C8 | 核心只编排，兼容性在适配器 | 核心只负责：把条目放进布局、启用/禁用插件、恢复状态、在适配器缺失/禁用/未授权时显示占位。“怎么打开某种文件/网页/本机应用”全部在适配器插件里。 |
| C9 | 诚实的显示方式 | 每个适配器声明它的内容到底显示在哪里：应用内阅读器、应用内网页面板、外部程序（由工作台启动与切换，**不嵌入**）。不承诺任意 Windows 程序可以嵌入面板；任何嵌入都必须对具体程序逐个验证后才能开放。 |
| C10 | 权限有范围、由用户批准 | 插件权限必须带范围（已注册的根、指定域名、指定程序路径/哈希），没有“任意文件/任意网络/任意进程”。v1 第三方插件没有网络与进程权限。 |
| C11 | Agent 默认只读 | Agent 默认只能读。写入按任务以“批量计划”展示，用户批准后执行；覆盖显示差异；删除进入应用管理的可恢复暂存区。 |

## 2. 首屏布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 本地知识工作台 [读文献 ▾] [ 🔍 文件名 / 路径 / 正文（待做）   ] ◐外观 ⌘ │  顶栏
├───────────────┬──────────────────────────────────────────────────────┤
│ 收藏           │ ┌ 读书笔记.md ×  待办.txt × ┐┌ 讲义.pdf × ┐            │
│  ⭐ 读书笔记.md │ │                           ││  共 3 页 − 120% ＋       │
│  📁 论文 ▸     │ │   Markdown 渲染            ││  [PDF 页面]             │
│ 根目录          │ │                           ││                         │  中央：dockview
│  🗂 kb-sample ▾│ │                           ││                         │  标签页 + 分栏
│    📁 笔记 ▾   │ │                           ⇔ 拖动调整宽度              │  （可拖标签分栏）
│      📄 …  ⇥ ☆ │ └───────────────────────────┘└─────────────────────────┘│
│ [＋选择文件夹…] │                                                        │
│ [输入路径回车 ] │                                                        │
├───────────────┴──────────────────────────────────────────────────────┤
│ kb-sample：已索引 9 个文件 · 监听中 ⟳      （扫描中显示进度与“取消”） │  状态栏
└──────────────────────────────────────────────────────────────────────┘
```

- 左侧栏（宽度可拖动）：**收藏**（文件/文件夹/根，可直接展开收藏的文件夹）→ **根目录树**（懒加载）→ 注册根（文件夹选择器或输入路径）。
- 每行悬停出现：`⇥` 在右侧分栏打开、`☆/★` 收藏切换；根行另有 `✕` 移除登记（不删文件）。
- 中央：dockview 标签页区域，可拖动标签到任意边缘形成分栏，分隔条可拖动。
- 顶栏搜索：输入即搜，↑↓ 选择，Enter 打开，Alt+Enter 在右侧打开。
- 状态栏：每个根的索引状态（扫描进度/文件数/监听状态/错误），扫描中可取消，空闲时可手动重新扫描。

- 顶栏左侧：**工作区切换器**（按项目分组列出全部工作区；新建、另存为、改名/设置项目、导出、导入、删除、应用布局预设）。
- 顶栏右侧：**外观**菜单（外框样式、阅读区样式、浅色/深色/跟随系统三项独立选择；安装主题包）；`⌘` 按钮 / `Ctrl+Shift+P` 打开命令面板（工作区、外观、布局预设都有对应命令）。
- 侧栏底部：**插件**面板（由内置插件通过面板扩展点贡献），显示每个插件的状态（已启用/已禁用/不兼容/出错/未授权）与启用开关；主题包也在这里列出。
- 状态栏右侧：当前工作区名、当前外观组合。
- 视觉：三个方向 A 安静书房 / B 专业工具 / C 明亮卡片都作为**可安装、可切换的主题包**提供，各有浅色与深色（目前为占位实现，由主题外包定稿，见 [05-主题接口.md](05-主题接口.md) 与 `theme-kit/`）。

## 3. 核心用户流程

1. **注册根**：点击“选择文件夹…”或输入路径 → 根出现在树中并自动展开 → 状态栏显示“扫描中…N”，完成后“已索引 N 个文件 · 监听中”。重叠根（父子关系）、不存在路径、应用数据目录会被拒绝并给出原因。
2. **浏览与阅读**：展开目录 → 单击文件在当前分组打开新标签；已打开则切换过去。`⇥` 在右侧新分栏打开，实现并排阅读。
3. **收藏**：任意文件/文件夹/根点击 ☆。文件被外部改名/移动后收藏自动跟随；被删除则显示为划线“失联”而不是静默消失。
4. **搜索**：文件名/路径（v1 切片）；正文全文（txt/md/PDF，第一个可用版本，见 §4），结果点击跳到文件（PDF 跳到页）。
5. **恢复现场**：关闭再打开，根、收藏、目录展开状态、所有标签页、分栏结构与尺寸、侧栏宽度、窗口大小全部恢复。
6. **外部修改**：用户在资源管理器/编辑器里改动、Agent 写入，树、标签内容、标题、收藏和索引自动更新；应用关闭期间的改动在下次启动对账扫描时补上。
7. **误操作恢复**（应用/Agent 执行的修改）：删除/移动/覆盖前看到预览（影响多少文件、多大、是否冲突）→ 执行 → 在操作记录中撤销；撤销时若原位置被占用或文件已被再次修改，提示冲突并提供“保留两者”。
8. **工作区**：工作区是全局的（不属于某个根），可以按“项目”分组，可以同时引用多个根中的文件。
   - 新建（空布局）/ 另存为（复制当前标签、分栏、尺寸与阅读进度）/ 改名并设置项目 / 删除（只删布局记录，不动文件，至少保留一个）。
   - 一键打开与切换：顶栏切换器或命令面板“切换到：…”。切换前自动写完当前工作区的改动（不弹“保存/丢弃”）；所有改动自动保存，退出应用前也会先写完。
   - 恢复内容：标签、分栏结构与尺寸、侧栏宽度、PDF 页码/缩放/页内位置、Markdown/文本滚动位置、插件视图状态（如 CSV 排序）。
   - 每个面板的视图状态属于工作区；插件的全局设置存在插件私有存储里，不随工作区切换。
   - 导出 `.kblayout.json` / 导入：文件中没有绝对路径、没有文件内容；导入到另一台电脑时按“根名 + 相对路径”重新匹配本机文件，匹配不到的标签显示“文件不可用”占位。
   - 布局预设（单栏、左右两栏、上下两栏，以及主题包提供的预设）只改分栏排列，不改打开的文件与阅读进度。
   - 由更新版本应用保存的工作区（布局版本更高）以只读方式提示，不会被旧版本覆盖。
9. **用插件扩展**：在插件面板启用/禁用插件；首次启用需要权限的插件时弹出授权说明（读取已注册根内文件、通过操作服务修改文件、访问网络……）；插件不兼容时显示原因并保持禁用；禁用插件后其打开的标签变为占位（“视图不可用，改用默认视图打开”），重新启用后自动恢复；卸载时询问保留或删除插件数据。
10. **打开方式**：同一文件可有多个视图（例：csv 可以“表格”或“文本”打开，md 可以“渲染”或“源码”打开），默认使用优先级最高的视图，用户可在标签菜单“打开方式…”中切换并记住选择（待做）。
11. **切换外观**：外框样式、阅读区样式、浅/深色分别选择，可以任意组合（例如“B 的外框 + A 的阅读区 + 深色”）。切换即时生效，打开的文件、分栏位置与阅读进度不变。外观是全局设置，不随工作区切换。
12. **资料集合**（待做）：按主题挑选一组文件（可跨根），作为打开文件、建工作区、搜索范围的入口；与工作区的区别：集合回答“哪些资料”，工作区回答“现在怎么摆、读到哪”。
13. **混合条目**（分阶段）：工作区中的条目分三种来源——文件、网页、本机应用。本轮只有“文件”可用；网页与本机应用条目可以存在于工作区中（例如从更新版本导入），显示“暂不可用”占位并原样保留，不影响其他面板。


## 4. 范围

### v1 切片（本轮已实现，见 README 与验证报告）
- 注册/移除根（选择器 + 路径输入），多根。
- 收藏文件/文件夹/根（引用资源 ID）。
- 目录树浏览；文本（含 GBK 自动识别）、Markdown（相对图片、脚本过滤）、PNG/JPG 等图片、PDF（按需渲染页面）阅读；不支持格式提示面板。
- dockview 标签 + 分栏 + 拖拽调整；重启全量恢复布局。
- 文件名/路径搜索（SQLite FTS5 trigram）。
- 后台 worker 扫描（进度 + 取消）+ chokidar 监听 + 重命名/移动识别。
- 服务层的删除/覆盖/移动 + 预览 + 撤销（**仅服务层与测试，UI 未接入**）。

### 第二轮新增（已实现于切片）
- 统一视图注册 API；Markdown/PDF/文本/图片/不支持格式均为内置插件 `builtin.readers` 的注册项。
- 演示插件 `demo.csv-table`（按第三方插件对待：需授权 fs.read）在运行时注册 csv 表格视图，与内置视图同处分栏布局，状态（排序）随布局保存与恢复。
- 插件状态与私有存储（应用数据目录，按插件 id 隔离，随备份导出）；插件面板；命令面板与快捷键；三套主题（设计令牌）。
- 视图类型缺失时的占位恢复。

### 第三轮新增（已实现，Linux 上自动化验证；Windows 未验证）
- 命名工作区：创建、另存为、改名、按项目分组、删除、一键切换、自动保存（切换/退出前立即写完）、重启恢复、跨根、布局版本号与迁移（v1/v2 → v3）、导出/导入 `.kblayout.json`、布局预设。
- 工作区条目模型：`{itemId, sourceKind 'file'|'web'|'app', adapterId, ref, displayMode, state}`；面板只引用 itemId。现有阅读器全部改为 **file 适配器**；web/app 只有类型与“暂不可用”占位。
- 插件 manifest 增加 `contributes.adapters`（来源类型、显示方式、匹配、带范围的权限、状态版本）；权限校验拒绝无范围的网络/进程权限，v1 第三方插件不能申请网络/进程。
- 主题接口 1.0（见 05）：外框/阅读区/布局预设三轴，105 个令牌，15 个组件 × 7 种状态，受限 CSS；A/B/C 改为主题包（占位），各有浅色与深色；外观菜单三项独立选择；主题包安装。
- 功能基准界面与 `npm run theme:shots`；主题外包开发包 `theme-kit/`。
- 应用内对话框（替代 `window.confirm`/`prompt`），插件授权对话框显示权限范围。

### 分阶段路线（产品负责人确认）
| 阶段 | 内容 | 显示方式 |
| --- | --- | --- |
| P1 | 文件阅读器 + 工作区面板（本轮完成核心部分）；正文搜索；沙箱视图插件 | 应用内阅读器 |
| P2 | 网页面板：每个网页适配器只能访问声明的域名，用户批准 | 应用内网页面板 |
| P3 | 指定的本机应用适配器（逐个程序接入，程序路径/哈希由用户批准） | 外部程序（由工作台启动与切换，不嵌入）；任何“嵌入面板”都必须对该程序、该版本单独验证后才能作为实验选项开放 |

### 适配器默认行为（产品负责人决定，2026-10-03）
| # | 决定 | 含义 |
| --- | --- | --- |
| D1 | 网页子资源只允许声明的域名 | web 适配器的导航与子资源（脚本、图片、样式、子框架）都限制在 manifest 声明并经用户批准的域名内；部分站点因 CDN 资源被拦截而显示不全时，由适配器作者补充声明域名，再次请用户批准 |
| D2 | 域外链接确认后用系统浏览器打开 | 网页面板中指向未声明域名的链接不在面板内打开，提示“将在系统浏览器中打开 <网址>”，用户确认后才打开 |
| D3 | 卸载插件后工作区条目保留为占位 | 卸载插件不删除任何工作区中的条目及其状态，这些面板显示“适配器未安装”占位；卸载对话框提供“同时从所有工作区移除这些条目”选项（默认不勾选） |
| D4 | 外部程序继续运行 | 关闭外部程序条目的面板、或退出工作台时，不关闭外部程序；重新打开工作区时也不自动启动它 |
| D5 | v1 没有加密的密钥存储 | 插件不能保存密码、令牌；需要登录的网站只依赖网页面板自己的会话分区（不进入备份与导出） |
| D6 | 启动外部程序前自动备份 | 启动外部程序并把已注册根中的文件交给它之前，先把这些文件备份到应用备份库并写操作记录（actor=`app:<程序>`），程序修改后可撤销 |
| D7 | v1 第三方插件只能本地开发者模式安装 | 没有插件商店、没有签名；用户在设置中打开“开发者模式”后从本地文件夹安装，安装时显示来源路径与所需权限 |

本轮不实现适配器宿主能力（适配器 SDK 草案中的 H1–H13 中尚未完成的部分，见 02 §12.3），以上决定在 T13/T14/T19/T20 实现时遵守。

### 第一个可用版本（下一阶段，必须）
- **第一个实用的搜索**：文件名、路径，以及 txt / md / 有文本层的 PDF 的**正文**；结果显示片段，PDF 跳到命中页。OCR 以后再做。（目前只有文件名/路径搜索。）
- **设计系统定稿**：主题外包按 05 交付 A/B/C 的浅色与深色，产品负责人选默认组合。
- **插件化补全**：v1 第三方插件 = 用户在**开发者模式**下从本地文件夹安装的**沙箱视图插件**（file 适配器）；没有商店、没有签名；第三方插件 v1 没有网络；后台插件逻辑以后再做。安装/卸载 UI、权限管理页、“打开方式…”。
- **资料集合**：挑选文件、跨根、作为工作区与搜索的入口。
- **Agent**：默认只读；写入按任务以批量计划呈现、用户批准；覆盖显示差异；删除进入可恢复暂存区（本地 HTTP JSON-RPC + MCP 包装，见 02 §7）。
- 操作记录面板（UI）：查看、预览撤销、冲突处理；文件操作 UI（重命名、移动、删除到暂存区）。
- 备份/恢复与根重新映射的 UI。
- Windows 安装包，并在**真实 Windows** 上验收（交叉打包产物不算；见 03 T9）。

### v1 之后
- 网页面板（P2）与指定本机应用适配器（P3），见上表。
- 后台插件逻辑（抽取器、索引器等，运行在独立进程）。
- 笔记、标签、引用（PDF 选区/页码锚点）、知识链接（双链/反链）。
- Office/EPUB 等格式阅读、OCR、扫描版 PDF 的正文。
- 多窗口、云同步、多设备协作。

### 明确不做（v1）
- 不复制/托管文件；不在根目录内写任何元数据文件。
- 不接入云端服务；Agent 接口只监听 127.0.0.1。
- 第三方插件不能联网、不能启动进程；没有后台插件。
- 不承诺把任意 Windows 程序嵌入面板。
- 工作区里不保存文件内容、密码、令牌等秘密；单个工作区布局上限 512 KB，单个条目状态上限 16 KB。
